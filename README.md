# 精品日报

Chrome Manifest V3 本地经营分析扩展，147图标，版本3.5.2。

完整说明：[精品日报原理以及使用说明.md](精品日报原理以及使用说明.md)。

## 构建与安装

下载的成品目录（包含manifest.json）可直接在Chrome加载；GitHub成品仓库根目录即扩展目录。下面构建命令仅适用于包含package.json和src的源码工程。

```powershell
npm install
npx playwright install chromium
npm run build:extension
npm run build:release
```

在Chrome的 `chrome://extensions` 开启开发者模式，加载本项目 `dist-extension`。`build:release` 还会生成正常版与混淆分发版两个ZIP；两版保持相同扩展ID，更新时重新加载同一扩展，不卸载、不更换Manifest公开key。无需启动服务器。

分发包解压后选择直接含 `manifest.json` 的目录加载。公开成品仓库同时提供正常版与混淆分发版两个ZIP，根目录是混淆版。不要同时加载两个版本：它们使用同一扩展ID。混淆处理应用JS及导入/备份worker，不处理第三方DuckDB运行时、WASM、HTML或CSS；不生成源码映射。

**保护边界：** 浏览器必须能执行扩展代码，因此这不是加密。仓库同时公开正常版，任何人都可以直接分析未混淆代码；混淆分发版仅适合单独分发时提高逆向成本，不提供仓库层面的保密。旧提交中也已有未混淆版本和规则文档。需要真正保密的规则应迁到受控服务端。

## 本版规则

3.5.2将“月份对比”升级为可按日/按月切换的“对比图表”；经营汇总对象对比可直接绘图，多对象图卡每页最多8张，每图可导出PNG/CSV。发布脚本生成正常版和混淆分发版两个ZIP；两者都发布到成品仓库。浏览器必须执行可读取的JavaScript，混淆不能提供不可破解的加密保护。

3.5.1将月份、SPU筛选固定在顶部。选月份后切按日期会自动填写仓库实际日期，优先主表、VCPO独有月用VCPO；不连续月份限制继续生效，手动改日期也不混入跳过月份。恢复全部日期同时清除月份限制。左右轴采用一致的单位校验：同单位自由放置，不同单位冲突阻止并提示，支持一键交换，空轴隐藏；超过两种单位明确提示。三处图表轴配置分别随仓库保存。

3.5兼容VCPO“月份”表头、缺日期和缺转换列；仅在月份可确定时补为1日，数据质量保留依据，已有完整日期不改。1—10月四来源表头及VCPO逐行验证见 [兼容说明](VCPO_COMPATIBILITY_20261022.md)。单对象月份对比支持最多两指标合图、左右双轴与柱线；所有折线相关图可开启平滑并保存设置。

3.4新增可组合的月份透视、全局不连续月份多选与按月/按日期模式。图表分析新增多对象月份对比，每指标独立柱状/折线图及月份横排表，支持排序导出、无记录与真实0区分、主表日期覆盖提示和完整设置记忆。月份含年份，原日期区间保留，月比率按汇总分子/分母计算。

3.3.1修复7/8月旧版促销表头误判：实时表可缺少非计算用的“新旧料号转换”；已入账兼容旧列名Original balance并保留原金额，不自动换汇。空表与缺表分开标记，兼容依据写入数据质量。旧版已误判的7/8月文件需重新导入，主表仍去重；详见 [四文件调查](PROMOTION_SOURCE_AUDIT_20261021.md)。

- 一个XLSX包含主合并表、VCPO、实时促销、已入账促销四Sheet，均按表头识别，可改名、换序、重排唯一字段或增加说明行。
- 初次导入必须有主表；已有对应期间主表后可只补费用，预览明确确认期间及空表含义。
- 四来源独立去重与修订；促销缺表/空表让本次涉及整月该来源按0，历史暂停保留，补源默认替换或可选合并；VCPO及费用独有对象仍保留。
- 指标以每日销售数据-集合为依据，默认SPU为主表AZ/VCPO AJ，原AQ/AA作为独立维度。
- 默认原日报对账范围，可切换全部有效记录；保留Excel文本通配符对数字0的区别。
- 参数始终按月份自动填写，CNY按月推导不足用6.6，VCPO除数1.14、UK乘数0.74、SKU比例0.03为明确默认，逐字段记录来源；支持指定模板强制覆盖全部月份。未使用的两个天数输入移除。
- 站外推广全局固定0，含旧库数据，页面及导出明确标记已排除。全站原币TOTAL按原表使用USD值并说明。
- 原日报对账页面/TOTAL入口移除，两种分析范围保留；日期旁可只重置日期。
- 数据质量按月份和文件展示四来源状态、归零事件、默认/推导/手动参数依据。透视数值旁不再展示参考小字，真实错误仍--，说明随分析导出保留。
- 完整仓库与SQL默认无损gzip压缩（json.gz/sql.gz），保留历史；兼容恢复旧JSON/SQL，SQL解压后仍可用于SQLite。
- 旧库升级有预览与备份入口，原始值、批次和历史不丢弃。
- 三层毛利分别展示，总推广占比纳入默认列；库存三项移除。
- 经营汇总/日期汇总分别记住指标和顺序，可恢复默认；配置随仓库及完整SQL/JSON备份迁移。
- 经营概览支持最多12项独立面板指标、调整先后、自适应排版，配置随仓库保存。

实际来源及公式证据：[TWO_SHEET_RECONCILIATION.md](TWO_SHEET_RECONCILIATION.md)。程序验收：[VALIDATION.md](VALIDATION.md)。原业务Excel只读核对，不随扩展发布。

历史Markdown保留Excel证据；与现版冲突的旧描述以完整说明及3.3验收为准。卸载扩展、清理浏览器数据会丢失仓库，更新前请备份。


# 精品日报功能介绍

精品日报把导入的经营数据整理成表格和图表，方便查看销售、广告、毛利以及人员和商品的表现。

三个主要页面，可以这样理解：

| 页面 | 主要看什么 | 例如 |
|---|---|---|
| 经营分析（菜单名称：经营汇总） | 看谁贡献大、哪些商品值得关注 | 这个月哪个销售的销售额最高？ |
| 日期汇总 | 看每天发生了什么变化 | 哪天广告费增加了，销售额却没增加？ |
| 图表分析 | 用图看趋势、结构和不同月份的表现 | 张三6、7、8月的销售额和广告费有什么变化？ |

以下以当前3.5.2版功能为准。文中的人名和月份只是操作示例，不代表实际经营结果。

## 一、经营分析：从整体看到具体的人和商品

### 1. 先看整体情况

页面上方的经营概览，可以集中查看销售额、广告花费、毛利、广告销售额等重要数字。

你可以自己选择最关心的指标，最多放12项，也能调整顺序。例如把“销售额、广告花费、发货毛利”放在最前面，每次打开先看这几个数。

下面的趋势图可以更换指标，查看销售和投入的变化。SPU贡献饼图可以选择看前几名，例如Top5、Top10，也能改为按广告花费等指标查看。

### 2. 按自己想看的方式汇总

同一份数据，可以按部门、团队、销售、站点、SPU、ASIN、月份等不同方式查看，也可以组合起来。

| 想了解的问题 | 可以选择的分析维度 |
|---|---|
| 各部门表现怎么样？ | 部门 |
| 某个部门里，各团队分别做了多少？ | 部门 → 团队 |
| 每个销售主要靠哪些商品出单？ | 销售 → SPU |
| 每个月整体做了多少销售额？ | 月份 |
| 张三每个月表现怎么样？ | 销售 → 月份 |
| 7月各销售分别做了多少？ | 月份 → 销售 |

这里的箭头表示逐层展开。例如选择“部门 → 团队 → 销售”，先看到每个部门的汇总，点击展开箭头，再看下面的团队和销售。父级汇总会一直保留，方便边看整体、边看明细。

### 3. 自选指标、排序、找重点

在“指标管理”中勾选想看的列，例如销售额、毛利、广告花费、ACOS等，不需要的列可以隐藏。

点击表头可以排序。例如按销售额找主要贡献者，按广告花费找投入较大的商品，按毛利找需要进一步检查的对象。展开后的排序会在各自父级内部进行，不会把不同团队的人员混到一起。

指标选择和顺序会记住，下次打开不用重新勾选。

### 4. 点击名称，查看文字分析和ASIN

点击部门、销售、SPU等名称，可以打开基于当前数据生成的文字分析，查看销售规模、广告表现、主要贡献商品等内容。

ASIN列表支持按站点切换、搜索、选择展示指标和排序。点击ASIN可以打开对应站点的Amazon商品页；勾选多个同站点ASIN，还能生成一个集中查看它们的搜索链接。不同站点不能混在一个聚合链接里。

### 5. 把多个对象放在一起比较

“对象对比”可以一次勾选多个销售、部门、站点或商品，放在同一张表里比较，还能按指标排序和导出。点“绘制对比图”会把当前对象、指标和筛选条件带到图表分析。

**使用例子：看7月德国站各销售的表现。**

1. 在顶部“月份”中勾选7月，站点选择德国；SPU也能直接在顶部筛选。
2. 分析维度选择“销售”，指标勾选销售额、广告花费和毛利。
3. 点击销售额表头排序，先看主要贡献者，再点击姓名查看具体商品。

## 二、日期汇总：看每天的变化，找到异常发生的时间

### 1. 每天一行，方便连续检查

日期汇总把数据按天排列，每一行代表一天，可以查看当天的销售额、订单或件数、广告花费、毛利等指标。

它适合回答这些问题：

- 销售是从哪天开始增长或下降的？
- 广告费突然增加，具体发生在哪天？
- 哪几天毛利明显偏低？
- 调整广告后，接下来几天的数据发生了什么变化？

### 2. 只看需要的日期、人员或商品

可以选择具体起止日期，也可以切为“按月”，一次查看一个或多个月份的每日记录。

比如只勾选6月和8月，日期表就只看这两个月，不包含7月。站点、团队、销售、SPU等筛选也可以一起用，方便查看某个人或某个商品的每日表现。

选好月份后切为“按日期”，日期框会自动填写这些月份在仓库中的实际起止日期。如果选6月和8月，切日期后仍不包含7月；手动改日期也保留这个限制，旁边会显示“仅看所选月份”。清空月份即可按连续日期查看。

日期旁的重置按钮可以同时恢复全部日期和月份。SPU、站点、销售等其他筛选条件会保留。

### 3. 保留自己常用的每日指标

日期汇总有独立的指标配置。你可以在经营分析里多看商品和人员表现，在日期汇总里只保留销售额、广告费、毛利等几项，方便快速检查。

需要做日报或进一步核对时，可以导出当前分析表。

**使用例子：检查某个SPU最近一周的广告表现。**

1. 选择最近一周的日期，再筛选这个SPU。
2. 勾选销售额、广告花费、广告销售额和ACOS。
3. 找出变化明显的日期，结合当天的广告调整、促销或业务情况继续检查。

ACOS可以简单理解为“广告费占广告销售额的比例”。它能帮助观察广告效率，但不能只凭一个比例判断商品是否赚钱。

## 三、图表分析：把数字画出来，更容易看出区别

### 1. 根据问题选择图表

| 图表 | 适合看什么 | 使用例子 |
|---|---|---|
| 折线图 | 一段时间内的变化 | 看销售额逐日或逐月走势 |
| 面积图 | 数值规模随时间的变化 | 看广告投入的变化幅度 |
| 柱状图、条形图 | 不同对象谁高谁低 | 比较各销售的销售额 |
| 堆叠柱状图 | 可以相加的几部分分别有多少 | 查看同单位指标的组成；有包含关系的金额不要重复相加 |
| 饼图、环形图 | 主要贡献来自哪里 | 看Top10 SPU的销售贡献 |
| 双轴组合、柱线图 | 两个数值差距较大的指标一起看 | 柱子看广告费，折线看ACOS |
| 散点图 | 投入与产出的关系 | 找广告费高、销售额相对低的SPU |
| 矩形树图 | 从整体看各部分的规模 | 看部门、团队到商品的销售贡献 |
| 热力图 | 哪些组合明显偏高或偏低 | 日期和站点交叉，看销售额变化 |

饼图只显示选中的前几名，不合并“其他”。例如选Top10，占比表示这10个对象内部的贡献比例，不是全部商品中的比例。

### 2. 用对比图表看一个人或商品

进入“对比图表”，可以按月份或日期查看同一个销售、SPU、部门等的表现。按月份时，未选月份就看全部已导入月份；按日期时，每天一个位置，跟随上方日期范围，已勾的月份仍起限制作用。

只选择一个对象时，最多可以同时展示两个指标，合在一张图上。两个指标可分别使用左边和右边的刻度，还可以切换柱状、折线、柱线。

例如选择“销售张三”，勾选“销售额”和“广告花费”，就可以看这两项在6、7、8月是一起增长，还是投入增加而销售变化不大。

### 3. 比较多个人或商品

同时选择张三、李四等多个对象后，每个指标会单独画一张图，方便比较。按勾选指标的顺序每页最多显示8张图，超过时翻页；下面的明细表仍包括全部指标。

按月份时，下面的表格每个对象一行，月份横向排列。按日期时，每个日期和对象占一行；点击列名可排序。单张图可下载PNG和CSV，完整明细也能单独导出。

**使用例子：比较两个销售最近三个月的表现。**

1. 上方切为“按月”，勾选6、7、8月。
2. 打开“图表分析 → 对比图表”，对象类型选“销售”。
3. 勾选张三、李四，再选择销售额、广告花费、毛利。
4. 先看图中的变化，再在下面的表格查看具体金额。

### 4. 调整图表的查看方式

折线相关图可以开启“平滑折线”，让连线更圆滑；它只改变线条外观，不改变数据。

同单位指标可都放左轴、都放右轴，也能一左一右。金额和百分比等不同单位不能放到同一侧，操作冲突时会提示原因并保持原图；想把两边对调，点击“一键交换左右轴”即可。只有一侧在用时，另一侧的空刻度自动隐藏。

对比图表的对象、指标、图形、左右轴等设置会保存。切换按月/按日期会同步上方时间方式；按日图只显示所选日期中的已导入数据，不把只计入月度TOTAL的费用摊到每天。

月份旁会显示主表已经导入的日期范围。如果10月只导入到15日，显示的就是已有数据，不会自动估算成整月。

看表时也要区分三种情况：**0表示确实为零，“无记录”表示该对象当天或当月没有记录，“--”表示该项暂时无法计算。** 遇到疑问，可以到“数据质量”查看来源和处理说明。

毛利按当前报表规则计算，不等同于最终净利润；当前已排除站外推广费用。具体字段解释和数据处理规则，见 [精品日报原理以及使用说明](精品日报原理以及使用说明.md)。
