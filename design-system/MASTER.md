# 精品日报工作台

Applied skills: ui-ux-pro-max and frontend-design. Audience: Amazon operations analysts.

- Dense desktop workspace, persistent sidebar, dataset header, sticky filters, unframed table sections. Mobile uses a compact navigation rail.
- Palette: paper #ffffff, canvas #f5f7f8, graphite #20272b, action teal #0d766b, chart blue #4275d6, warning amber #ad650c.
- Typography: Segoe UI with Microsoft YaHei for Chinese; 13px body, 22px page titles; tabular numbers; no remote fonts.
- Table and actual data charts carry the identity. No marketing hero, decorative imagery, gradients or nested cards.
- Functional controls use Lucide icons and accessible labels. Popovers and dialogs use shadcn/ui patterns with Radix primitives. Clear loading, error and empty states.
- Review: removed the skill search's enterprise landing pattern because the requested product is an operational BI application. Retained density, contrast and restrained motion recommendations.
